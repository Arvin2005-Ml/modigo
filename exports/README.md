# خروجی تفریح‌ها — ۱۳ نوامبر ۲۰۲۶

**مجموعهٔ جاری — ۱۴ نوامبر ۲۰۲۶:** [فهرست ۷۰۰ تفریح](../content/real-catalog-index.md)، [JSON کامل](../content/real-catalog.json) و [CSV](../exports/real-activities-700.csv) شامل ۴۰۰ تجربهٔ دارای مکان/شهر/منبع و ۳۰۰ دستور عملی خانگی است. [قرارداد ورود و محدودیت‌های واقعی](../docs/28-real-catalog-700.md). شمارهای ۸۸۱/۴۳۱/۴۱۳ در ادامه، خروجی تاریخی release قبلی‌اند و تعداد زندهٔ Mongo را نشان نمی‌دهند.


**انطباق DRAMMA — ۱۴ نوامبر۲۰۲۶:** همهٔ۴۳۱ محتوای پخته و شش قالب نمایشی دارای هدف و ارجاع به قدم اجرایی‌اند؛ نگاشت۳۰۰ تفریح ایران موردی است. انتشار و شروع، این قرارداد را کنترل می‌کنند. [شرح و محدودیت‌ها](../docs/27-dramma-alignment.md).

- `activities.csv`: همهٔ۸۸۱ فعالیت تعریف‌شده برای ورود اولیه؛۴۵۰ بذر خام مالک و۴۳۱ نمونهٔ پختهٔ تألیفی. تمام متادیتای موجود حفظ شده؛ متادیتای بانک در ستون‌های `source_metadata.*` و محتوای پخته در `content.*` است. آرایه‌ها JSON داخل سلول‌اند. فایل UTF-8 با BOM برای نمایش فارسی در Excel است؛ مقدار ثبت‌نشده خالی می‌ماند.
- `iran-activities.csv`: فقط۳۰۰ تفریح تازهٔ بیرونی و هزینه‌دار ایران با متن کامل، زمان، وسایل، شروط اجرا و دامنهٔ شواهد. قیمت‌ها unknown و برنامه‌ها نیازمند بررسی محل و رزرو هستند؛ فهرست برنامه و قیمت زنده نیست.
- `cooked-activities.json`: متن کامل و متادیتای۴۳۱ نمونهٔ پخته در `activities`، شامل۴۱۳ فعال و۱۸ کنارگذاشته‌شده در تعریف اولیه. شش قالب آمادهٔ پخت بانک در `prepared_fixtures` جدا هستند؛ این شش قالب اثبات اجرای job یا انتشار بذر نیستند. متادیتای عمومی بانک، تعریف برچسب‌ها، تعدادها، منابع `iran_sources` و محدودیت منبع نیز داخل فایل است.

منبع خروجی فایل‌های موجود پروژه و همان mapping واردکنندهٔ برنامه است. بانک Markdown تألیفی جایگزین، منبع import جاری نیست و دوباره شمرده نشده است. هیچ UUID دیتابیس یا زمان پخت حدس زده نشده است. `cooked_at=null` یعنی زمان واقعی پخت در منبع ثبت نشده؛ `exported_at` فقط زمان خروجی‌گرفتن است. `initial_state` و `initial_active` وضعیت ورود اولیه‌اند و وضعیت فعلی دیتابیس را اثبات نمی‌کنند. محتوای demo خروجی واقعی مدل یا دارای تأیید انتشار عمومی نیست.

فرمان بازتولید از ریشهٔ پروژه، با وابستگی‌های موجود API:

```sh
.venv/bin/python scripts/export-activities.py
```

این ابزار فقط فایل‌ها را می‌خواند؛ سرویس، job runner یا اتصال DB ایجاد نمی‌کند و تنظیمات محرمانه را نمی‌خواند. برای خروجی جاری MongoDB باید در محیط دارای driver و دسترسی عمومی، دادهٔ زنده جداگانه خوانده شود؛ fallback اجرایی افزوده نشده است.

بررسی برش فعلی در [سند26](../docs/26-iran-paid-catalog.md) ثبت است: schema و بازتولید۳۰۰ محتوای جدید، ورود بی‌تکرار، فیلترهای سخت و مسیر پیشنهاد تا بازخورد بررسی شدند؛۱۳۱ تست پایتون و۱۹ تست فرانت، typecheck و build موفق‌اند و۷ تست Mongo زنده اجرا نشده‌اند. `diagnose-db` به‌علت نصب‌نبودن PyMongo ناموفق بود؛ خروجی زندهٔ MongoDB تهیه نشد.
