# طراحی بصری: نرم، صمیمی و خلوت

## جهت هنری

حس یک یادداشت کوچک و خوش‌ساخت برای وقت آزاد؛ زمینهٔ گرم، کارت‌های روشن، سبز ملایم و تایپوگرافی خوش‌خوان. فضای سفید بیش از تزئین. صفحهٔ داشبورد پر از نمودار، gradient بزرگ، تصویر استوک شلوغ، شیشه‌ای‌سازی و confetti پیش‌فرض نداشته باشد.

## توکن‌های پایهٔ پیشنهادی

این‌ها تصمیم طراحی اولیه‌اند؛ نسبت کنتراست ترکیب نهایی در پیاده‌سازی سنجیده شود.

| token | مقدار | کاربرد |
| --- | --- | --- |
| `background` | `#F8F6F1` | زمینهٔ گرم |
| `surface` | `#FFFFFF` | کارت |
| `text` | `#24352E` | متن اصلی |
| `text-muted` | `#536259` | توضیح خوانا |
| `primary` | `#315B48` | عمل اصلی با متن سفید |
| `primary-soft` | `#E7EFE8` | انتخاب و پس‌زمینهٔ نرم |
| `accent` | `#EEDBC8` | تزئین محدود، با متن تیره |
| `border` | `#DDE3DC` | جداکننده؛ برای focus کافی نیست |
| `focus` | `#1E6047` | outline با offset |
| `danger` | `#A43232` | خطا همراه متن |

فونت فارسی self-hosted با مجوز روشن: Vazirmatn، fallback sans-serif. فایل، نسخه و مجوز در repo ثبت شود. سایز body موبایل ۱۶، line-height حدود ۱٫۸؛ عنوان اصلی ۲۸ تا ۳۶، عنوان کارت ۱۸ تا ۲۰. ارقام نمایشی با `Intl.NumberFormat('fa-IR')` و ورودی عددی پذیرای ارقام فارسی/عربی/لاتین؛ JSON اعداد واقعی و تاریخ‌ها ISO UTC باشند.

Spacing روی شبکهٔ ۴ پیکسل: ۴،۸،۱۲،۱۶،۲۴،۳۲،۴۸. radius کنترل ۱۲، کارت ۲۰، badge ۹۹۹. سایهٔ کم‌رنگ فقط برای عمق ضروری؛ border نرم اولویت دارد. عرض محتوا ۱۰۸۰، ستون پرسش‌نامه ۵۶۰، padding موبایل ۲۰، دسکتاپ ۳۲.

## چیدمان پیشنهادی نتیجه

```text
┌───────────────────────────────────────┐
│ فانیلو                       ذخیره‌ها │
│ این یکی شاید الان بهت بچسبه            │
│ ۳۰ دقیقه · خونه · تنهایی     ویرایش   │
│                                       │
│ [ عنوان تجربه ]                       │
│ یک تصویر ذهنی کوتاه و مشخص            │
│ ۱۵ دقیقه · رایگان                     │
│ چون دنبال یه کار کم‌انرژی بودی         │
│ [ ببینمش ]                     ذخیره │
│                                       │
│ [قبلی]    پیشنهاد ۲ از ۲       [بعدی] │
│ ۵ تعویض باقی‌مانده · [یه پیشنهاد دیگه]│
└───────────────────────────────────────┘
```

فقط یک کارت در ستون وسط با حداکثر عرض ۶۴۰ پیکسل، با اسکرول طبیعی و متن کامل. زیر کارت، کنترل صریح قبلی/بعدی و جای مرور نمایش داده شود؛ swipe اجباری یا حرکت خودکار ندارد. در انتهای تاریخچه شمارنده و دکمهٔ دریافت گزینهٔ تازه قرار می‌گیرند. دکمه‌های مرزی و حین درخواست غیرفعال‌اند؛ مرور بعد از اتمام سهمیه فعال می‌ماند. وضعیت با live region و ارقام فارسی خوانده شود.

## اجزای لازم

`Button`, `IconButton`, `Input`, `ChoiceChip`, `RadioCard`, `BudgetInput`, `StepProgress`, `ActivityCard`, `ConstraintSummary`, `ActivitySteps`, `BottomSheet/Dialog`, `Toast`, `EmptyState`, `ErrorState`, `Badge`, `JourneySummary` و اجزای جدول ادمین. از یک مجموعهٔ آیکون SVG سازگار با مجوز ثبت‌شده استفاده شود؛ icon-only باید accessible name داشته باشد.

لوگو فعلاً wordmark سادهٔ «فانیلو» است. عکس یا تصویر تولیدی برای تحویل MVP لازم نیست. در صورت اضافه‌کردن تصویر، باید به خوانایی کمک کند و فقط کارت اول را به تصویر وابسته نکند. asset عمومی و placeholder از URL خارجی دائمی بارگیری نشود.

حرکت‌های ۱۲۰ تا ۱۸۰ میلی‌ثانیه برای hover و تغییر انتخاب؛ تعویض کارت بدون جابه‌جایی بقیهٔ صفحه. celebration پایان، یک تغییر کوچک در نشان است؛ صدا و لرزش پیش‌فرض خاموش. dark mode خارج از نسخهٔ اول، ساختار tokenها آمادهٔ توسعه باشد.

## چک بصری تحویل

بازبینی در عرض‌های ۳۶۰،۳۹۰،۷۶۸،۱۴۴۰؛ بدون overflow افقی. RTL متن، آیکون برگشت و جای label را کنترل کن؛ رشتهٔ ایمیل و کد LTR موضعی. zoom دویست درصد، keyboard کامل، متن بلند فارسی، عنوان کارت چندخطی، بودجهٔ بزرگ و حالت بدون نتیجه بررسی شود. خروجی screenshot ثابت برای سه صفحهٔ سؤال، تک‌پیشنهاد با مرور و جزئیات در گزارش تحویل لازم است.
