# شرح نیاز و دامنه

**تصمیم جاری مالک — ۹ نوامبر ۲۰۲۶:** همهٔ اجراها، حتی localhost، به MongoDB واقعی روی endpoint عمومی متصل می‌شوند؛ fallback حافظه‌ای حذف است. [سند24](24-mongodb-storage.md) بر تصمیم قبلی سند21 مقدم است.

## مسئله

«وقت آزاد دارم، اما نمی‌دانم با این حال و شرایط چه کار کنم.» کاربر به یک لیست بلند یا گفت‌وگوی طولانی نیاز ندارد؛ باید بتواند ظرف حدود یک دقیقه به انتخاب برسد. هدف طراحی، کم‌کردن اصطکاک تصمیم است؛ اثر واقعی آن باید بعداً اندازه‌گیری شود.

## خواسته‌های قطعی مالک

۱. بانک ۴۵۰ فعالیت در چارچوب DRAMMA، هر بُعد ۷۵ فعالیت. ۲. چند سؤال دربارهٔ وقت، همراه، بیرون‌رفتن، حال و هزینه. ۳. نمایش یک پیشنهاد، حداکثر شش تعویض و مرور رایگان پیشنهادهای دیده‌شده؛ دو سؤال نیاز جاری و ترجیح بُعد بر پایهٔ انتخاب‌های پیشین طبق [23](23-single-suggestion.md). ۴. ایجنتی برای آماده‌کردن محتوای خام. ۵. احراز هویت و پنل ادمین. ۶. گیمیفیکیشن مشخص. ۷. استایل نرم، خودمانی، مینیمال. ۸. Next.js، React، Tailwind و MongoDB؛ بک‌اند پیشنهادی FastAPI. ۹. معماری مونولیت ماژولار. ۱۰. استفاده از API تهیه‌شدهٔ GapGPT با مدل اعلام‌شدهٔ مالک.

## نسخهٔ اول

لندینگ، ثبت‌نام/ورود/خروج/بازیابی، پروفایل سبک، پرسش‌نامهٔ موقعیتی، یک نتیجه، جزئیات، شش تعویض و مرور قبلی/بعدی، ذخیره، شروع و پایان تجربه، سابقه، بازخورد اختیاری، امتیاز و نشان، تنظیمات و حذف حساب. پنل ادمین برای بانک و نسخه‌ها، صف پختن، تأیید/انتشار، کاربران و گزارش تجمیعی. عملیات و تست قابل اجرا بدون اتصال مدل.

## خارج از نسخهٔ اول

شبکهٔ اجتماعی، چت عمومی، گروه‌یابی با غریبه‌ها، رزرو، پرداخت، نقشه و مکان زنده، پیش‌بینی هوا، push notification، leaderboard، اپ بومی، fine-tuning، vector DB، bandit آنلاین و microservice. شهر اختیاری فقط برای نسخه‌های بعدی؛ GPS دریافت نشود. پیشنهادهای دیده‌شده انتخاب‌های جایگزین‌اند؛ برنامهٔ تفریحیِ پشت‌سرهم از آن‌ها ساخته نشود.

## شاخص پذیرش محصول

کاربر تازه‌وارد روی موبایل بتواند بدون آموزش، سؤال‌ها را جواب دهد، دلیل کوتاه و قابل فهمی برای پیشنهاد ببیند، تجربه را شروع و پایان دهد و بازخورد را رد کند. ادمین بتواند یک بذر را بپزد، پیش‌نویس را اصلاح و نسخه‌ای را منتشر کند. خاموش‌بودن GapGPT پیشنهادهای منتشرشده را مختل نکند.

هدف‌های اولیهٔ سنجش: میانهٔ زمان پاسخ به سؤال‌ها کمتر از ۶۰ ثانیه و نرخ شروع بهتر از خط پایهٔ ساده. این‌ها هدف‌اند، نه ادعای نتیجه؛ حدود پس از پایلوت بازنگری می‌شوند.
