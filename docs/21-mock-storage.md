# تصمیم پیشین ماک — لغوشده در ۹ نوامبر ۲۰۲۶

مالک اکنون صراحتاً اتصال به MongoDB واقعی روی endpoint عمومی را خواسته است. دستور پیشین `DATA_BACKEND=mock`، ممنوعیت driver/اتصال و پاک‌شدن داده با restart دیگر جاری نیستند. مرجع اجرایی جدید [24-mongodb-storage.md](24-mongodb-storage.md) است.

factory برنامه فقط `DATA_BACKEND=mongo` را می‌پذیرد؛ خطای اتصال به حافظه fallback ندارد. برای localhost هم URI عمومی از `.env` سمت سرور خوانده می‌شود. تنها double حافظه‌ای در پوشهٔ تست قرار دارد و با متغیر محیطی قابل فعال‌کردن نیست.

تاریخچهٔ تصمیم قبلی در ADR16 و گزارش‌های تاریخ‌دار باقی است؛ از آن برای دستور اجرای جدید استفاده نشود. تک‌پردازشی‌بودن فعلی و اجرای worker داخل API حفظ شده‌اند، اما داده‌های محصول در Mongo پایدارند. اتصال زنده و شرایط سرور باید با فرمان `check-db` سند24 بررسی شوند.
